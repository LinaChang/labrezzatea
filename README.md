# 風玥茶研所：本機離線網站

原站：https://www.labrezzatea.com/

## 本次成果與驗證

已儲存 **86 個主要頁面、401 個來源檔案，約 98.9 MB**。主要頁面包括：9 個主頁、4 個茶品分類、23 個茶品、23 個產品詢問頁、21 篇新聞、6 篇文章。另保留 14 個原站 Feed 連結回傳的 HTML 版本，不重複計入主要頁面。

檔案檢查涵蓋 5,956 個本機參照，其中 2,246 個導覽連結全部有對應檔案。可見內容的圖片參照均有下載；來源樣式仍引用少數未取得的圖示字型、舊版 LESS 匯入及背景圖，詳見 `validation-report.json`。首頁腳本動態組合的 5 個箭頭／播放按鈕圖檔已於再次連線時補齊。其餘 13 個來源網址確認回傳 HTTP 404，包括 5 個圖示字型、5 個舊版 LESS 相依檔、2 張樣式背景圖與原站 sitemap.xml；不能保證所有細部外觀與原站完全相同。

瀏覽器預覽權限未獲准，因此未完成畫面驗證。已檢查的公開連結沒有 PDF、Word、Excel 或 ZIP 文件。網站地圖依可探索的公開連結建立，並非後台全部資料的匯出。

## 開啟方式

1. 雙擊 `start-preview.cmd`（需要 Python 3）。
2. 瀏覽器會開啟本機網址，預設為 http://127.0.0.1:8080/ 。
3. 網站地圖位於 http://127.0.0.1:8080/sitemap.html 。
4. 關閉預覽時，在命令視窗按 Ctrl+C。

也可以直接開啟 `offline/index.html`，所有已下載頁面、圖片、樣式和字型都使用相對路徑；建議使用本機伺服器，讓瀏覽器相容性更穩定。預覽只使用本機檔案，不會代理請求回原站。

## 檔案結構

- `offline/`：可攜式離線網站。站內頁面、圖片、文件、CSS 與 JS 保留原網址目錄；首頁為 `index.html`。
- `offline/_external/`：網站引用的外部靜態素材，按原網域分資料夾存放。
- `offline/sitemap.html`：可點選的完整擷取頁面清單。
- `offline/sitemap.xml`：以來源網址列出的 Sitemap。
- `SITEMAP.md`：原網址與離線頁面的對照清單。
- `mirror-manifest.json`：下載時間、每一個網址、檔案路徑、檔案大小、失敗項目與站外連結。
- `validation-report.json`：本機連結檢查結果與未取得資源清單。
- `scripts/mirror.py`：可重複執行的下載／連結轉換程式，只使用 Python 標準函式庫。
- `.mirror-cache/`：原始回應快取；不需要帶到其他電腦。移除快取後執行下載程式可重新擷取最新內容。

## 擷取範圍

從首頁遞迴追蹤公開站內連結、分頁，以及頁面／CSS／腳本所引用的靜態素材。原站未提供可用的 `/sitemap.xml`，因此這份 Sitemap 是依實際可到達的公開頁面建立，無法列出原站未連結、需登入或由後端資料庫才可取得的頁面。

保留原始頁面內容與版型，移除原站 `<base>`，並將已下載的頁面與素材連結改為本機相對路徑。查詢參數形式的頁面使用 `__q_` 雜湊檔名，避免覆蓋；靜態素材的快取版本參數會移除。

Facebook、分享、Email、電話與站外網站連結保留原目的地，仍須網路或其他程式。遠端嵌入內容以離線提示代替；未使用的 YouTube／Vimeo 播放器 API 不包含在離線副本內。寄信、表單送出、登入及其他伺服器功能無法由靜態備份重現。

## 重新下載

在本資料夾執行：

```powershell
python scripts/mirror.py
```

下載程式需要網路；離線預覽不需要。搬移時只需複製 `offline/` 與預覽程式，並保留目錄相對位置。

不使用網路、只從現有下載快取重新產生網站：

```powershell
python scripts/mirror.py --cached-only
python scripts/validate_offline.py
```
